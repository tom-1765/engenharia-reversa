## 8. COMO USAR ISTO PARA COMPARAR PERFIS  *(instrução para a skill — pode manter como está)*

Ao analisar qualquer perfil, gere uma **Parte C — Comparação com a minha estratégia**, cruzando o
perfil-alvo contra estas dimensões:

| Dimensão | Pergunta de comparação |
|---|---|
| **Posicionamento** | O ângulo dele conversa com o meu posicionamento (seção 0)? Ou é outro jogo? |
| **Fluxos de receita** | Como ele monetiza? O que dá pra aprender do modelo dele? |
| **Mix de conteúdo** | Onde ele cai no meu eixo de tipos (seção 4)? Está longe do meu mix-alvo? |
| **Audiência** | Ele fala com alguma das minhas audiências (seção 3)? |
| **Mecanismo de engajamento** | Que CTA/gatilho usa (comment-bait, tag-bait, salvar)? Qual dá pra portar? |
| **Fronteiras** | Ele cruza alguma linha que eu não quero cruzar (seção 7)? |

**Saída da Parte C — sempre 3 baldes:**
- 🟢 **ROUBAR** — formato/estrutura/gatilho que encaixa direto (dizer qual audiência e qual fatia do mix).
- 🟡 **ADAPTAR** — funciona, mas precisa ser traduzido pro meu nicho (dizer *como*).
- 🔴 **IGNORAR** — bomba pra ele, mas conflita com a minha marca (dizer *por quê*).
